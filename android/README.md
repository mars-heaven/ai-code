# 일감장부 (안드로이드)

임가공 작업장의 일감 접수 · 직원 공임 정산 · 거래처 계산서를 휴대폰 한 대에서 처리하는 장부 앱입니다.
데이터는 모두 휴대폰 안(Room 데이터베이스)에 저장되며, 서버가 필요 없습니다.

## APK 받는 방법 (안드로이드 스튜디오 없이)

1. 깃허브 저장소에서 **Actions** 탭을 엽니다.
2. 왼쪽에서 **일감장부 APK 빌드** 를 고릅니다.
3. 가장 최근 실행을 누르고, 아래 **Artifacts** 의 `ilgam-jangbu-debug-apk` 를 내려받습니다.
4. 압축을 풀면 나오는 `app-debug.apk` 를 휴대폰으로 옮겨 설치합니다.
   - 설치할 때 "출처를 알 수 없는 앱" 허용이 필요할 수 있습니다.

> 빌드를 직접 돌리고 싶으면 Actions 화면의 **Run workflow** 버튼을 누르면 됩니다.

## 안드로이드 스튜디오로 여는 경우

`android` 폴더를 열면 됩니다. (JDK 17, Android SDK 35)
Gradle wrapper 바이너리는 저장소에 두지 않으므로, 처음 열 때 안드로이드 스튜디오가
알아서 wrapper 를 내려받습니다. 명령줄에서 쓰려면 한 번만 아래를 실행하세요.

```
cd android
gradle wrapper --gradle-version 8.9   # 최초 1회
./gradlew assembleDebug
```

## 설계 메모

### 단가는 기록 시점 값을 저장합니다
일감과 작업기록에는 그 시점의 단가를 함께 저장합니다.
나중에 품목 단가를 바꿔도 이미 지나간 정산 금액은 흔들리지 않습니다.

### 중복 지급 · 중복 청구를 막는 방식
작업기록(`work_logs`)에는 `payrollId`(급여 묶음)와 `invoiceId`(청구 묶음)가 있습니다.

- 값이 비어 있으면 **아직 정산되지 않은 건**입니다.
- 마감하면 그 기록들에 묶음 번호가 찍히고, 다음 마감 집계에서 자동으로 빠집니다.
- 덕분에 직원마다 마감일이 달라도, 중간에 일부만 먼저 지급해도 두 번 계산되지 않습니다.
- 마감을 취소하면 묶음이 풀려 다시 미정산 상태로 돌아갑니다.
