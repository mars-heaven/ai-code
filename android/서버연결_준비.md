# 서버 연결 준비 (사장님 계정으로 한 번만)

앱을 여러 사람이 같이 보려면 파이어베이스라는 구글 서비스에 자리를 하나 만들어야 합니다.
**숫자 자료만 올리므로 카드 등록이 필요 없고, 요금도 나오지 않습니다.**

이 일은 구글 계정 주인이 직접 해야 해서 대신 해 드릴 수 없습니다.
아래 순서대로 하시고, 마지막에 나오는 파일 하나만 주시면 나머지는 제가 붙이겠습니다.

---

## 1. 프로젝트 만들기

1. https://console.firebase.google.com 에 구글 계정으로 들어갑니다.
2. **프로젝트 추가** 를 누릅니다.
3. 이름은 아무거나 좋습니다. 예: `ilgam-jangbu`
4. 애널리틱스(사용 통계)는 **꺼도 됩니다**. 안 씁니다.

## 2. 안드로이드 앱 등록

1. 프로젝트 화면에서 안드로이드 아이콘을 누릅니다.
2. **패키지 이름** 에 정확히 이렇게 넣습니다:

   ```
   com.ilgam.jangbu
   ```

3. 앱 닉네임은 `일감장부` 정도로 적습니다.
4. **SHA-1 인증서 지문** 칸이 나옵니다. **구글 로그인에는 이게 꼭 필요합니다.**
   아래 6번을 먼저 보고 값을 넣어 주세요.
5. **google-services.json 다운로드** 를 누릅니다. → **이 파일을 주시면 됩니다.**

### 6. SHA-1 지문 구하기

지금 드리는 APK는 테스트용 서명이라, 그 서명의 지문을 넣어야 로그인이 됩니다.
컴퓨터에서 아래를 실행하세요.

**윈도우 (명령 프롬프트)**

```
keytool -list -v -keystore "%USERPROFILE%\.android\debug.keystore" -alias androiddebugkey -storepass android -keypass android
```

**맥 / 리눅스**

```
keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android -keypass android
```

나오는 것 중 `SHA1:` 로 시작하는 줄의 값을 복사해 넣습니다.

> **중요**: 이 지문은 **그 컴퓨터의 테스트 서명** 것입니다.
> 지금 APK는 깃허브에서 빌드되므로 서명이 다릅니다.
> 그래서 실제로는 **깃허브 빌드 서명의 지문**도 함께 넣어야 합니다.
> 파일을 주시면 제가 깃허브 빌드 쪽 지문을 뽑아 알려 드리겠습니다.
> (파이어베이스는 지문을 여러 개 넣을 수 있습니다.)

## 3. 구글 로그인 켜기

1. 왼쪽 메뉴 **빌드 → Authentication** 에 들어갑니다.
2. **시작하기** 를 누릅니다.
3. 로그인 방법 목록에서 **Google** 을 고르고 **사용 설정** 합니다.
4. 지원 이메일을 고르고 저장합니다.

## 4. 데이터베이스 만들기

1. 왼쪽 메뉴 **빌드 → Firestore Database** 에 들어갑니다.
2. **데이터베이스 만들기** 를 누릅니다.
3. 위치는 **asia-northeast3 (서울)** 을 고릅니다. 한국에서 빠릅니다.
4. 모드는 **프로덕션 모드** 를 고릅니다. (아래 5번에서 규칙을 넣습니다)

## 5. 보안 규칙 넣기

1. Firestore Database 화면 위쪽의 **규칙** 탭에 들어갑니다.
2. 이 폴더의 **`firestore.rules`** 파일 내용을 통째로 복사해 붙여 넣습니다.
3. **게시** 를 누릅니다.

이 규칙이 "그 업체 식구 명단에 있는 사람만 그 업체 자료를 본다"를 강제합니다.
**이걸 안 넣으면 아무나 자료를 볼 수 있으니 꼭 하셔야 합니다.**

---

## 그다음

`google-services.json` 파일을 주시면 `android/app/` 에 넣고 서버 기능을 켭니다.

파일이 없는 동안에도 앱은 지금처럼 **폰 안에만 저장하며 그대로 돌아갑니다.**
'함께 보기' 화면에 "아직 서버에 연결되어 있지 않습니다" 라고만 뜹니다.

## 요금

- 숫자 자료(Firestore)는 **무료 플랜(Spark)** 으로 씁니다. 카드 등록 없습니다.
- 계산서 **사진은 서버에 올리지 않습니다.** 폰에만 둡니다. 사진이 요금의 거의 전부라 이 결정으로 비용이 0이 됩니다.
- 무료 한도는 하루 읽기·쓰기 횟수와 저장 용량으로 정해지는데, 몇 사람이 쓰는 장부로는 근처에도 못 갑니다.
